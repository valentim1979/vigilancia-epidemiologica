Vigilância Universal — SRAG

Síndrome Respiratória Aguda Grave — 15ª RS Maringá/PR

30/08/2026 15:59

Dica

Ano de referência: 2026  |  Fonte: SIVEP-Gripe (módulo hospitalar)  |  Escopo: 30 municípios da 15ª Regional de Saúde

Notificações de SRAG hospitalar na área de abrangência da 15ª RS. A Vigilância Universal abrange todos os hospitais e serviços de saúde — registra casos graves com necessidade de hospitalização, internações em UTI e óbitos.

Notificações por estabelecimento

Nota

Dados agregados por estabelecimento e semana epidemiológica — sem microdados individuais. Atualizados a cada execução de SCRIPT_Unificado.R.

Código 
serie_semanal = d3.rollups(
  dados_filtrados,
  v => ({
    casos: d3.sum(v, d => d.casos),
    obitos: d3.sum(v, d => d.obitos),
    uti: d3.sum(v, d => d.uti),
    confirmados: d3.sum(v, d => d.confirmados)
  }),
  d => d.SEM_EPI
).map(([SEM_EPI, vals]) => ({ SEM_EPI, ...vals })).sort((a, b) => a.SEM_EPI - b.SEM_EPI)
Código 
total_casos   = d3.sum(dados_filtrados, d => d.casos)
total_obitos  = d3.sum(dados_filtrados, d => d.obitos)
total_uti     = d3.sum(dados_filtrados, d => d.uti)
letalidade_pct = total_casos > 0 ? (total_obitos / total_casos * 100).toFixed(1) : "0.0"

Circulação viral no estabelecimento selecionado

Código 
dados_virus_estab = FileAttachment("dados/circulacao_viral_estabelecimento.csv").csv({typed: true})
Código 
virus_filtrados = estabelecimento_sel === "Todos os Estabelecimentos"
  ? dados_virus_estab
  : dados_virus_estab.filter(d => d.ESTABELECIMENTO === estabelecimento_sel)
Código 
virus_total = d3.rollups(
  virus_filtrados,
  v => d3.sum(v, d => d.positivos),
  d => d.virus
)
  .map(([virus, positivos]) => ({ virus, positivos }))
  .filter(d => d.positivos > 0)
  .sort((a, b) => d3.descending(a.positivos, b.positivos))
Código 
virus_total.length > 0
  ? Plot.plot({
      title: `Vírus identificados por RT-PCR — ${estabelecimento_sel}`,
      width: 850,
      height: 320,
      marginLeft: 150,
      marginRight: 50,
      x: { label: "Casos positivos" },
      y: { label: null },
      marks: [
        Plot.barX(virus_total, { x: "positivos", y: "virus", sort: { y: "-x" }, fill: "#0057A3", tip: true }),
        Plot.text(virus_total, {
          x: "positivos", y: "virus", text: d => d.positivos,
          dx: 4, textAnchor: "start", fontSize: 10, fill: "#333333"
        })
      ]
    })
  : md`*Sem detecções virais registradas para **${estabelecimento_sel}** no período carregado.*`
Código 
virus_semanal_estab = d3.rollups(
  virus_filtrados,
  v => d3.sum(v, d => d.positivos),
  d => d.SEM_EPI,
  d => d.virus
)
  .flatMap(([SEM_EPI, porVirus]) =>
    porVirus.map(([virus, positivos]) => ({ SEM_EPI: +SEM_EPI, virus, positivos }))
  )
  .sort((a, b) => a.SEM_EPI - b.SEM_EPI)
Código 
virus_semanal_estab.length > 0
  ? Plot.plot({
      title: `Tendência semanal de vírus respiratórios — ${estabelecimento_sel}`,
      width: 850,
      height: 380,
      marginLeft: 50,
      x: { label: "Semana epidemiológica" },
      y: { label: "Casos positivos" },
      color: { legend: true, range: d3.schemeSet1 },
      marks: [
        Plot.lineY(virus_semanal_estab, { x: "SEM_EPI", y: "positivos", stroke: "virus", tip: true }),
        Plot.dot(virus_semanal_estab, { x: "SEM_EPI", y: "positivos", stroke: "virus", r: 2 })
      ]
    })
  : md`*Sem série semanal de vírus disponível para **${estabelecimento_sel}**.*`
Nota

Nota

Nota metodológica — Canal endêmico

O canal endêmico delimita zonas de referência para o número esperado de casos de SRAG por semana epidemiológica, com base no comportamento histórico observado no período pós-pandêmico.

Período de referência: 2022–2025.

Os anos de 2020 e 2021 foram excluídos por representarem perfil epidemiológico atípico decorrente da pandemia de COVID-19, com padrão de circulação viral incompatível com a vigilância de rotina. O ano de 2019 foi excluído por ser pré-pandêmico, período anterior à reorganização do perfil de vírus respiratórios que se estabeleceu após 2022.

Zonas de classificação:

  • 🟢 Esperado: entre o P25 e P75 do histórico — comportamento dentro do padrão
  • 🟡 Alerta: entre o P75 e P90 do histórico — atenção reforçada recomendada
  • 🔴 Epidêmico: acima do P90 do histórico — situação que requer resposta imediata

A linha tracejada verde representa a mediana histórica semanal (referência central).

Limitação: com quatro anos de referência (2022–2025), os percentis são estimativas com maior incerteza do que o recomendado internacionalmente (mínimo de 5 anos). O canal se estabilizará progressivamente à medida que novos anos pós-pandêmicos forem incorporados. Os resultados devem ser interpretados com cautela, especialmente nas semanas com menor volume histórico de casos.
